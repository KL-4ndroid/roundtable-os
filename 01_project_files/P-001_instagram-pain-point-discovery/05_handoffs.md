# Handoffs｜任務交接

## H-001｜交接給 01 受眾洞察室

【交接來源】
00｜總控室_策略與決策中心

【任務背景】
我們正在用 Instagram 找到手作品牌主、市集攤主與小型電商品牌的真實痛點。第一輪不做銷售，也不做工具開發，只做 14 天痛點探索。

【已得到的結論】
1. 先驗證 4 類痛點：新品上市、商品文案、市集出攤、活動復盤。
2. 成功標準不是粉絲成長，而是使用者原話與重複痛點。
3. 需要先把痛點問題問清楚，再交給 Instagram 內容室產出內容。

【需要下一個角色協助的問題】
請你協助整理：
1. 4 類痛點各自的表層問題與深層問題。
2. 每類痛點適合用哪些問題收集原話。
3. 哪些訊號代表這個痛點值得繼續驗證。
4. 哪些訊號只是低價值互動。

【限制條件】
語氣：溫柔、實用、像經營筆記
目標客群：已經有商品、正在經營 IG 或出攤的小品牌主
不能做什麼：不要直接設計產品；不要假設受眾一定願意付費
必須保留什麼：使用者原話、反對意見、尚未驗證的假設

【希望輸出格式】
請用表格輸出：痛點類型 / 表層問題 / 深層問題 / 可問問題 / 高訊號回饋 / 低訊號回饋 / 備註

## H-002｜交接給 03 Instagram 內容室

【交接來源】
00｜總控室_策略與決策中心

【任務背景】
我們正在執行 `P-001｜Instagram 手作市集品牌主痛點探索`。目標是用 14 天 IG 貼文與限動，找到手作市集品牌主真實痛點。

【已得到的結論】
1. 第一輪只驗證痛點，不急著銷售模板。
2. 內容要能引出留言、限動回覆、私訊與使用者原話。
3. 內容類型可包含共鳴文、方法文、診斷文、限動投票、問答箱。

【需要下一個角色協助的問題】
請你把 14 天計劃轉成：
1. 每日 IG 貼文標題
2. 輪播大綱或短文草稿
3. 限動互動題目
4. CTA
5. 要觀察的痛點訊號

【限制條件】
語氣：溫柔但有方法、實用但不生硬
目標客群：手作品牌主、市集攤主、小型電商品牌
不能做什麼：不要焦慮銷售、不要保證成長、不要使用爆單話術
必須保留什麼：每篇都要能收集痛點回饋

【希望輸出格式】
請用 14 天內容表輸出：Day / 內容類型 / 主題 / 開頭鉤子 / 重點大綱 / 限動或 CTA / 要觀察的訊號

## H-003｜第 7 天回到總控室

【交接來源】
03｜Instagram 內容室 / 使用者實際回饋

【任務背景】
第一週內容發布後，需要判斷哪些痛點有訊號、哪些內容方向要調整。

【需要總控室協助的問題】
請判斷：
1. 哪一類痛點最有訊號？
2. 第二週是否要維持原計劃或調整？
3. 是否有痛點可以先更新到 pain point index？
4. 是否需要交給免費工具室做假測試？

【希望輸出格式】
訊號整理 / 採用建議 / 暫緩項目 / 第二週調整 / 需要更新文件
