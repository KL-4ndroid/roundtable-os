## Project name

Instagram 0 粉啟動｜手作市集品牌主共鳴內容

## Project type

Content launch / Audience building / Pain point validation

## Current status

BUILDING

## One-sentence description

為一個 0 粉的新 Instagram 帳號，先產出第一批能讓手作品牌主、市集攤主產生共鳴並願意追蹤的貼文，同時保留痛點觀察與顧問服務鋪陳。

---

## Source

- User revised priority
- New Instagram account with 0 followers
- Existing Féria positioning
- Existing pain point assumptions

---

## Target user or audience

優先吸引：

1. 已經有商品、但經營流程混亂的手作品牌主
2. 已經出攤或準備出攤的市集攤主
3. 想讓商品被理解，但卡在文案、陳列、活動安排的小品牌主
4. 有 IG / 官網 / Pinkoi / 私訊銷售的小型電商品牌
5. 花藝、香氛、陶藝、文具、甜點、選物等小眾創作者

暫不優先：

- 尚未開始販售商品的人
- 只想看泛 AI 教學的人
- 只追求快速流量或爆單方法的人
- 不願意整理資料、只期待被代操的人

---

## Problem / opportunity

目前帳號是 0 粉，新受眾還不知道這個帳號是誰、能幫她解決什麼、為什麼值得追蹤。

因此第一階段不應該只做「痛點探索」，而是先建立帳號的基本內容厚度與追蹤理由：

- 讓品牌主覺得「這個帳號懂我的卡點」
- 讓市集攤主覺得「這裡有我可以照著做的方法」
- 讓潛在顧問客戶知道這裡提供市集陪跑、品牌經營陪伴與痛點整理
- 用內容自然收集痛點回饋，而不是一開始就賣服務

---

## Current shared conclusion

1. 首要目標改為：先產出第一批 Instagram 貼文，讓 0 粉新帳號建立定位、內容厚度與追蹤理由。
2. 痛點探索仍保留，但改成內容中的次要目的，不再是唯一成功標準。
3. 第一批內容需要包含：帳號定位、自我介紹、品牌主共鳴、市集痛點、方法整理、顧問/陪跑服務暗示。
4. 不追求快速爆紅，先追求精準粉絲、收藏、轉發、留言與私訊。
5. 暫不做硬銷售頁、完整模板商品或 APP 功能。

---

## Current disagreements or open questions

1. 第一批貼文應該做 6 篇、9 篇，還是 12 篇？
2. 帳號一開始是否要明確說「顧問 / 陪跑服務」，還是先用內容建立信任？
3. 是否同步經營 Threads，作為短文觀察與導流來源？
4. 第一階段的追蹤成長目標要設定多少才合理？
